# Architecture
## Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).
In the beginning we were using handlebars with express to serve the the html pages, this is ideal for situations where server side redering is ideal due to large amount of content. In the last module we converted it to a SPA that handled the login in the browser(client side), which is ideal for light workloads and can achieve a snappier response. 

## Why did the backend use a NoSQL MongoDB database?
We chose to use the NoSQL MongoDB database because of its current position in the industry as a leading standard for non-relational mapping databases. Also as of recent news have become the leading standard for I believe managing the database using a new vector system.
